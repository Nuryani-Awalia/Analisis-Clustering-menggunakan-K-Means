# Analisis-Clustering-menggunakan-K-Means
Implementasi metode K-Means Clustering menggunakan Python untuk mengelompokkan data berdasarkan kemiripan karakteristik. Proyek ini mencakup preprocessing data, penentuan jumlah cluster optimal, proses clustering, visualisasi, serta analisis hasil pengelompokan menggunakan pendekatan Unsupervised Learning.
